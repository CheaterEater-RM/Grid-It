# Grid It

Grid It is a small RimWorld 1.6 mod that adds a simple map grid overlay.
It draws cell borders over the currently viewed map to make spacing, alignment,
and planning easier.

## How to use

- Enable the mod with Harmony loaded before it.
- Open a colony map.
- Use the Grid It button in the bottom-right play settings row to toggle the grid.

## Settings

The mod settings menu lets you:

- Pick quick grid colors: gray, black, or white.
- Set a custom RGB or hex color.
- Adjust opacity.
- Adjust border thickness.
- Hide the overlay button.

If the overlay button is hidden, any active grid overlay is turned off so it
cannot be left stuck on.
